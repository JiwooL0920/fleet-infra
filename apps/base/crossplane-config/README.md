# Crossplane Configuration - Infrastructure Configuration

Crossplane compositions and resource definitions for Infrastructure as Code platform.

## Purpose

- CompositeResourceDefinitions (XRDs) for cloud resource abstraction
- Composition definitions for complex infrastructure patterns
- S3 bucket compositions with LocalStack integration
- Template definitions for repeatable infrastructure patterns

## Dependencies

- **Depends on**: crossplane (requires Crossplane core platform and CRDs)
- **Depended on by**: crossplane-providers (providers reference compositions)

## Components

- S3 bucket composition and definition
- Infrastructure composition patterns
- Resource transformation and patching functions
