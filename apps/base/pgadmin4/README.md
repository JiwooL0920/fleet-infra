# pgAdmin4 - Database Management

Web-based PostgreSQL database administration interface for managing the PostgreSQL cluster.

## Purpose

- Web-based PostgreSQL database management interface
- Query editor and database object management
- Visual database design and schema management
- User and permissions management
- Secure authentication via External Secrets
- Direct connection to the PostgreSQL cluster

## Dependencies

- **Depends on**: postgresql-cluster (requires PostgreSQL cluster for database management)
- **Parallel with**: redisinsight (both database management tools)
