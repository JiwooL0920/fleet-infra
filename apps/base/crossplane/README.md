# Crossplane - Infrastructure as Code

Infrastructure as Code platform enabling cloud resource management through Kubernetes.

## Purpose

- Infrastructure as Code (IaC) platform for cloud resource provisioning
- Kubernetes-native approach to managing cloud infrastructure
- Custom Resource Definitions (CRDs) for cloud resources
- Foundation for cloud resource management and composition

## Dependencies

- **Depends on**: None (foundation infrastructure service)
- **Depended on by**: crossplane-config, crossplane-providers (require Crossplane CRDs and operator)

## Components

- Crossplane core operator deployment
- Cloud provider integration framework
- Composition and CompositeResourceDefinition capabilities
